# Confidential messages

Start a thread that only people with the password can read. The community server only keeps the encrypted text.

## Getting started

1. Choose the lock button in the message box, write the first message and a password of 8 characters or more, then choose **Lock and send**. Share the password outside Buzz.
2. Readers choose **Open** on the first message and enter the password. Replies in that thread then open by themselves until the app quits.
3. Every reply in the thread is encrypted when sent. While the thread is locked, nothing can be sent there. Files cannot be added yet, edits are not allowed, and a lost password cannot be recovered.
4. To protect an existing thread, choose **Move to a confidential thread** from its first message's menu. Its text is copied, encrypted, into a new thread; files are not copied, and the original stays until its writers delete it.
