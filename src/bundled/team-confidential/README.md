# Confidential messages

Send text that only people with the password can read. The community server only keeps the encrypted text.

## Getting started

1. Choose the lock button in the message box, then write the text and a password of 8 characters or more.
2. Choose **Encrypt**, then send the message. Share the password outside Buzz.
3. Readers choose **Open** on the message and enter the password. A lost password cannot be recovered, and attached files are not encrypted.
