# Work area

Arrange app pages side by side as panels, the way a video editor arranges its workspace.

## Getting started

1. Open **Work area** from the top tabs.
2. Add a panel from the row above, then drag its tab to an edge to split the area, or onto another panel to stack them. Drag the gaps to resize.
3. The arrangement is saved as you go, and saved with each UI profile in Settings, UI EDIT. **Reset arrangement** goes back to the default.
