# Chat display

Personalize how this device shows conversations: text size, message spacing, avatar size, conversation width, font, dark mode brightness and which top tabs appear.

## Getting started

1. Open Settings and find **Chat display**.
2. Pick the text size, spacing, avatar size, width and font you like. Changes apply at once.
3. Choose how bright dark mode is, and turn top tabs on or off. **Reset all** returns everything to the defaults. For the size of the whole app, use Appearance or Command-plus and Command-minus.
